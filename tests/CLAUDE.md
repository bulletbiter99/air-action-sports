## Standing rules (carried over)

- **Never hardcode dates inside relative-window test assertions** — they pass until the calendar walks the fixture out of the window, then `main` goes red with zero code changes (#291 expired exactly 30 days after authoring). Derive fixture dates from now using the endpoint's own key recipe.
- **A test can pass with the bug restored.** Three times this session. The 404 redirect test passed with the redirect back, because a `navigate()` fired from a timer is a React state update that advancing fake timers does not flush — wrap in `act()`. It also asserted on `window.location`, which `MemoryRouter` never touches. And a browser nav-timing check reported all-green by accepting the *previous* page's text. **Mutate every guard: break the code, watch the test fail, restore.**
- **The mockD1 first-handler-wins trap fired again in fresh test authoring** (beforeEach bind beat an in-test null re-bind → a 404 test passed via the wrong path... actually failed loudly, which is how it was caught). Pattern: per-test `bindX()` helpers, never entity binds in `beforeEach` when any test needs the entity absent.
- **mockD1 registers the FIRST handler per pattern** (re-confirmed): re-binding capabilities inside a test after `beforeEach` already bound them is a no-op — a capability-less actor needs its own `createMockEnv`.
- **`installClientFetch` MUTATES `globalThis.fetch`** — a mutation interceptor installed *before* render is silently discarded. Wrap after render. Cost four red tests.
- **`useEvents` caches per key at MODULE level** — without `clearEventsCache()` in `beforeEach`, the first fixture in a file satisfies every later test.
- **A shape-mock test can only pin the SQL *string*.** For anything where the question is whether SQLite would *accept* it — conflict clauses, CHECK constraints, PK collisions — use `freshSchemaDb()` (added to `tests/helpers/realSchema.js`; the cached `getSchemaDb()` is read-only by contract). Note better-sqlite3 enables foreign keys by default while D1 does not enforce them at runtime, so fixtures must seed real parent rows.
- **`rateLimit` middleware no-ops without `CF-Connecting-IP` header** — tests exercising rate-limit gating must set the header. The default key function returns empty string when the header is absent, and the middleware short-circuits via `if (!key) return next();`. (B5 test author.)
- **Admin pages never go network-idle** — the M4 `useWidgetData` cadence + `useTodayActive` shared subscription keep polling, which makes Claude_in_Chrome's `screenshot` / `read_page` / `get_page_text` / `find` tools time out (they wait for chrome.scripting `document_idle`). Workaround: use `javascript_tool` for inspection (different injection mode, no idle wait). Memory `feedback_browser_verification.md` updated this session with this guidance.
- **CI only runs vitest/visual on PRs to `main` or `milestone-*`** — a stacked PR based on a feature branch gets Workers Builds only. Retarget to `main` (then close+reopen, since retargeting alone does not re-trigger) before trusting green.
